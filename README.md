## 🔥 Featured Projects

### 🌲 WILDFIRE_V2 — India-Wide Wildfire Prediction System

> End-to-end machine learning and geospatial platform for predicting next-day wildfire risk across India.

* Trained on **9.4M+ historical samples** combining NASA FIRMS, ERA5, MODIS EVI, SRTM and ESA WorldCover data
* Uses **XGBoost, LightGBM, Random Forest, CatBoost and Logistic Regression** for model benchmarking
* Production XGBoost model achieved **0.9611 temporal ROC-AUC** on unseen 2025 data
* Uses strict temporal validation to evaluate generalization on future data
* Generates **0–1 fire-risk scores** and Low / Moderate / High / Extreme risk tiers
* Integrates **SHAP-based explainability** through a natural-language "WHY Engine"
* FastAPI backend for inference, analytics, FIRMS synchronization, chatbot and risk services
* Node.js API gateway for authentication and service routing
* React dashboard for interactive risk maps, EVI layers, fire overlays and analytics
* Region-aware caching and geospatial inference pipeline for scalable predictions

`Python` `XGBoost` `FastAPI` `React` `Node.js` `SHAP` `NASA FIRMS` `ERA5` `EVI` `Geospatial ML`

🔗 **[Repository](https://github.com/Vaasthav-06/WILDFIRE_V2)**

### 🛰️ WILDFIRE_CNN — Multimodal Wildfire Prediction

> Deep learning wildfire prediction system combining tabular environmental data with satellite imagery.

* Three-stage pipeline: **Tabular ML → CNN → Multimodal Fusion**
* Benchmarks **LightGBM, XGBoost and CatBoost**
* CNN experiments using **ResNet50 and EfficientNet**
* Automatic model scaling based on validation performance and overfitting
* Uses NASA FIRMS, weather data and satellite image tiles
* Combines image-based and environmental predictions through late fusion
* Served through **FastAPI + React**

`Python` `PyTorch` `CNN` `ResNet50` `EfficientNet` `XGBoost` `FastAPI` `React`

🔗 **[Repository](https://github.com/Vaasthav-06/CNN_BASED_WILDFIRE_PREDICTION)**
